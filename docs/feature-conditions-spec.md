# 特徵先行規格：分析條件是特徵，不是賠率

狀態：文件規格。本文沒有實作，沒有量度結果，也不是上線核准。合併本文不改變今日預測。

本文以香港繁體中文撰寫。對照的程式以 `main` 的 `d9cf37e55533b62f6977b3f03f2cef7ac2eeaf29` 為準（PR #6 已合併）。本文不改模型、API、測試、HTML、allowlist、查詢文字、憑證、環境、網域或 SSO。

2026-11-25 以 GET、不帶憑證重讀 `racing.hkjc.com` 的公開頁。當日這些頁面回傳 200，頁內沒有密碼欄，表格可讀。頁首有「登入」連結，讀取下述資料頁不需要登入。若日後同一網址改為要登入或內容不同，以當日頁面為準，本文這次讀到的範圍不再當成事實。

## 1. 目的，以及與 Size S 的關係

本框架的分析條件，是使用者點名的特徵：跑道與路程、晨操與試閘觀察、配備、傷患、跑法、檔位、騎練合拍度、負磅。場地狀況只在現行查詢已經回傳時，作為跑道與路程的上下文。

這些條件都不得定義為「以賠率高低驅動」。獨贏賠率高低不是分析條件。位置賠率高低不是分析條件。也沒有一條賠率基線，讓特徵在其上加減。

[Size S 規格](pack-s-features-spec.md) 與 `api/packS.js` 是另一件事。Size S 保留獨贏賠率做盤口基線，再談未量度調整。本文不改寫該文件，不把 Size S 收編成這個框架，也不沿用它的基線。

`GP_PACK_S` 維持預設關閉。本文不建議、也不實行把 `GP_PACK_S=1` 寫進任何環境。`api/packS.js` 裏檔位、負磅與體重的數字，檔案自己寫明是未經量度的實作預設。那些數字不是校準結果，不是勝率，也不是本框架的係數。本文不採用它們。

建議的新旗標名稱是 `GP_FEATURE_CONDITIONS`。它與 `GP_PACK_S` 是兩個名字。

- 預設關閉。未設定、空字串、`0`，以及任何不是精確字串 `1` 的值，都是關閉。
- 倉庫今日沒有這個名稱，也沒有程式讀取它。
- 本文不把 `GP_FEATURE_CONDITIONS` 寫進環境、工作流程或程式。
- 關閉，以及根本沒有程式讀取它，都表示今日生產路徑維持現狀。
- 本規格不是上線核准。日後即使另案實作，打開旗標仍須另案批准。本文不提供係數、權重、門檻或概率公式。

## 3. 騎練合拍：配對鍵與合拍度是兩件事

配對的雙方是該匹出賽馬在當前會議已經回傳的騎師與練馬師。用官方代碼，不用姓名。

- 騎師代碼是 `runner.jockey.code`。
- 練馬師代碼是 `runner.trainer.code`。
- 邏輯鍵是有序對：騎師代碼在前，練馬師代碼在後。
- 代碼先只去掉兩端空白。不去大小寫，不全形半形轉換，不以姓名反查代碼，也不讀 `trainerPreference`。
- 去掉兩端空白後，兩邊都必須是非空字串。否則該馬沒有配對鍵。
- 若日後另案需要字串，而且兩個代碼都不含半形豎線 `|`，字串為 `騎師代碼|練馬師代碼`。任一代碼含 `|` 時，本文不另定編碼；邏輯鍵仍是有序對。
- `name_ch`、`name_en`、官方賽果的 `jockey_ch` 與 `trainer_ch` 只可顯示。官方賽果沒有代碼，不能從已結束賽事的姓名造鍵。
- `runner.horse.code` 不是這條鍵的一部分。

配對鍵只回答「是哪一對」。合拍度、出賽次數、勝出次數、勝率、入位率、樣本門檻、時間窗與任何強弱分數，都還沒有定義。要計算它們，必須先有結算管道，並另案批准。本文不把獨贏或位置賠率當成這項統計的替身。

## 4. 新來源：晨操、試閘、傷患、跑法

以下網址都在 `https://racing.hkjc.com`，2026-11-25 以 GET 可讀，不在本倉庫的 allowlist。本文不把它們接上抓取、allowlist 或 API。頁面是 HTML，版面日後可以改。

現行網域維持不變：當前會議仍是 `https://info.cld.hkjc.com/graphql/base/`，已結束賽事的現有讀取仍是官方賽果頁。新頁與官方賽果同屬 `racing.hkjc.com`，但是不同路徑。本文不擴充 `api/officialResults.js`，也不准 `type=predict` 改去呼叫這些路徑。

### 晨操

會議頁：`https://racing.hkjc.com/zh-hk/local/information/localtrackwork`

已核對的查詢形式是 `?racedate=YYYY/MM/DD&Racecourse=ST` 或 `HV`，再加 `RaceNo=` 場次。`racedate=2026/11/25&Racecourse=HV&RaceNo=1` 回傳該場。

可讀內容：該場馬匹（含後備）的馬名、練馬師、近績字串，以及試閘、快操、踱步、游泳、馬匹跑步機、馬匹水中步行機、休歇等格，和「所有晨操紀錄」連結。格內文字可含地點，例如沙田或從化。

單駒明細：`https://racing.hkjc.com/zh-hk/local/information/trackworkresult?horseid=HK_年份_烙號`。已跟隨一條此形式連結，頁面有按日期排列的快操、踱步、游水紀錄。這是較長的歷史，不是會議頁那一格的複本。搜尋頁 `trackworksearch` 只確認標題為「晨操資料搜尋」，本文不定搜尋參數。

當日頁腳寫明：

- 每日晨操紀錄（馬匹游泳紀錄、馬匹跑步機紀錄、馬匹水中步行機紀錄除外）於當日中午十二時後公佈。
- 晨操紀錄只包括賽前三週內之紀錄。
- 同頁的試閘摘要只包括上賽至今，只計本地賽事。
- 游泳、跑步機與水中步行機於下一個工作天下午三時前上載。

缺值按第 2 節。會議頁的試閘格不能代替下一節的試閘詳細結果。近績字串不是跑法。晨操片段連結不是結構化觀察，本文不使用。

### 試閘

詳細結果：`https://racing.hkjc.com/zh-hk/local/information/btresult`

頁面以選單列出已公佈的試閘日期，值是 `DD/MM/YYYY`。頁內程式把該值倒轉成 `YYYY/MM/DD`，再前往 `?Date=` 這個參數。已核對 `?Date=2026/11/23` 顯示「試閘日期:23/11/2026」。選單以外的日期，本文不假設有資料。

可讀內容：組別、跑道與途程、場地狀況、全組時間、分段時間，以及每駒的馬名與括號內烙號、騎師、練馬師、排位、馬匹配備、頭馬距離、沿途走位、完成時間、結果、沿途走勢評述。結果可以是空白、及格、不及格或退出。

這頁的「沿途走勢評述」是該次試閘之後的評述，不是即將出賽的官方跑法標籤。不得用這句話給馬匹分類。

詳情是自由文字。本文不把文字收成嚴重程度分數，也不把通過日期收成體能分數。同名不同烙號不得併成一匹。

### 跑法，以及它不是沿途走勢

跑法是要求中的賽前條件。2026-11-25 重讀公開頁之後，沒有找到一個欄位，名稱或內容是某一匹出賽馬的賽前官方跑法分類。因此這項仍是新來源，而且來源尚未指明。在另案指明並批准之前，跑法保持缺值。

沿途走勢不是這項標籤。必須分開：

- `https://racing.hkjc.com/zh-hk/local/information/corunning?date=YYYYMMDD&raceno=場次` 的標題是「沿途走勢評述」，歸在賽事報告／賽果。已核對 `date=20261122&raceno=1`：這是沙田 2026-11-22 第 1 場，與倉庫樣本 `test/fixtures/official-results-2026-11-22-st.html` 同一場。表頭是名次、馬號、馬名、騎師、配備、走勢評述。評述在賽後撰寫。該場多格寫著「無特別報告」。「無特別報告」不是一種跑法。
- 賽果頁上的分段或走勢評述，同樣是賽後文字，不是賽前官方跑法標籤。
- 試閘頁的「沿途走勢評述」是試閘後評述，見上一節。
- 馬匹頁 `https://racing.hkjc.com/zh-hk/local/information/horse?horseid=HK_年份_烙號` 的往績有「沿途走位」。已核對 `HK_2023_J540`：那是歷次賽事的走位紀錄，頁內沒有名為「跑法」的欄。走位是賽後位置，不是賽前標籤。
- `last6run` 是近績，不是跑法。速勢能量頁 `/zh-hk/local/info/speedpro/formguide` 初次 HTML 寫著「正在加載數據」，其中沒有「跑法」。本文不把它當成跑法來源。

本文不設立「前置」「居中」「後上」或任何其他類別，也不准從上述評述推斷類別。

## 5. 位置只可做結算標籤或入位目標

位置（PLA 彩池，或官方賽果的「位置」派彩／名次）只可在賽後用作結算標籤或入位目標。

現有官方賽果解析已經讀到兩樣可以擔任這個角色的資料，而且只限已結束賽事：

- 名次：`runner.position`，來自賽果表的「名次」。
- 「位置」彩池的派彩列：`dividends` 裏彩池名為「位置」的勝出組合與派彩。倉庫樣本同一場有這個彩池。頁面欄名是「派彩 (HK$)」。那是賽後派彩，不是賽前位置賠率。

派彩金額不得倒數成概率，不得當作賠率高低，也不得當作基線。名次是完成名次。某一場位置彩池派幾個名次，以該場官方「位置」列實際支付的組合為準；本文不另定一個入位人數公式，也不把這件事實作成程式。

今日 `type=predict` 呼叫 `WIN_POOL_QUERY` 時，變數是 `oddsTypes: ['WIN']`。`GP_PACK_S` 不是精確的 `1` 時，模型字串是 `Odds-based probability model`。這條路徑只讀獨贏。本文不改它，也不批准改讀位置賠率。

`RACE_MEETINGS_QUERY` 的彩池清單裏出現 PLA，範圍是彩池投資、合併彩池或估紅利一類欄位，不是位置賠率節點。那些欄位不是本框架的分析條件。當前會議出賽馬上的 `finalPosition`、`winOdds`，以及獨贏節點的 `hotFavourite`、`oddsDropValue`、`bankerOdds`，都不是結算標籤，也不是分析條件。結算標籤只可來自已刊出的官方賽果。
