# 特徵先行規格：分析條件是特徵，不是賠率

狀態：已有實作，旗標預設關閉。本文描述 `api/featureConditions.js` 與 `api/races.js` 裏 `type=predict` 的現況。沒有量度結果，也不是上線核准。旗標保持關閉時，今日預測路徑不變。

本文以香港繁體中文撰寫。對照程式在基線 `d32f3ceccc7328a14335994ddfc6130be349b770` 之上。查詢文字、allowlist、憑證、網域與 SSO 沒有為本框架改動。預測頁文案按回傳的 `model` 與 `coefficientBasis` 切換，見第 8 節。旗標仍預設關閉。

2026-11-25 以 GET、不帶憑證重讀 `racing.hkjc.com` 的公開頁。當日這些頁面回傳 200，頁內沒有密碼欄，表格可讀。頁首有「登入」連結，讀取下述資料頁不需要登入。若日後同一網址改為要登入或內容不同，程式以當日頁面能否對上所請求的日期、馬場或場次為準；對不上就失敗關閉，不沿用舊頁。

## 1. 目的，以及與 Size S 的關係

本框架的分析條件，是使用者點名的特徵：跑道與路程、晨操與試閘觀察、配備、傷患、跑法、檔位、騎練配對鍵、已宣告負磅。場地狀況只在現行查詢已經回傳時，作為跑道與路程的上下文。體重只是與負磅相關的上下文。

這些條件都不得定義為「以賠率高低驅動」。獨贏賠率高低不是分析條件。位置賠率高低不是分析條件。也沒有一條賠率基線，讓特徵在其上加減。

[Size S 規格](pack-s-features-spec.md) 與 `api/packS.js` 是另一件事。Size S 保留獨贏賠率做盤口基線，再談未量度調整。本文不改寫該文件的係數，不把 Size S 收編成這個框架，也不沿用它的基線或它的數字。

`GP_PACK_S` 與 `GP_FEATURE_CONDITIONS` 是兩個名字，都預設關閉。本倉庫沒有環境檔，也沒有把任一旗標寫成啟用。

## 2. 旗標

`api/featureConditions.js` 的 `isFeatureConditionsEnabled` 讀取 `GP_FEATURE_CONDITIONS`。只有環境值精確等於字串 `1` 才算開啟。

下列都是關閉：未設定、空字串、`0`、`true`、`yes`、`on`、`01`、前後有空白的 `1`、以換行結尾的 `1`、`1.0`，以及任何其他不是該精確字串的值。

旗標關閉時，`type=predict` 與今日路徑相同，而且不抓第 5 節的新頁：

- `GP_PACK_S` 也不是精確字串 `1`：把當前會議的獨贏 `oddsNodes` 交給 `predictFromNodes`。模型字串是 `Odds-based probability model`。
- `GP_PACK_S` 是精確字串 `1`：仍走 Size S。特徵條件不介入，也不改 Size S 的輸出。

`type=odds` 不論這個旗標是否開啟，仍只讀獨贏彩池。變數仍是 `oddsTypes: ['WIN']`。

打開旗標不是上線核准。係數是未經量度的實作預設，不是校準結果。

## 3. 旗標開啟時的預測

`type=predict` 且旗標開啟時，不呼叫 `WIN_POOL_QUERY`，不呼叫 `predictFromNodes`，也不呼叫 `predictWithPackS`。即使 `GP_PACK_S` 同時是精確字串 `1`，這條路徑仍不用獨贏或位置賠率做條件或基線。

順序如下：

1. 以未改動的 `RACE_MEETINGS_QUERY` 讀當前會議。請求上的 `date` 與 `venue` 仍不篩選這張卡。用的是回傳清單裏的第一場會議，以及其中場次相符的一場。
2. 沒有會議，或該場不在卡上：成功，預測為空陣列，不抓 HTML。
3. 會議的 `date` 不能讀成香港日曆日期，或 `venueCode` 不是 `ST` 或 `HV`：`success: false`，錯誤碼 `SOURCE_ERROR`，不抓 HTML。純 `YYYY-MM-DD` 與 `YYYY/MM/DD` 當成日曆日期，不按行程時區挪一天。帶 `T` 的瞬間才換成 `Asia/Hong_Kong` 的日曆日。
4. 按該會議自己的日期、馬場與場次抓第 4 節的頁。任一頁身份不符、認不出、轉址後身份不同、或網絡失敗：失敗關閉，不退回賠率預測。HTTP 狀態不是成功是 `SOURCE_HTTP`，其餘是 `SOURCE_ERROR`。使用者看到的句子仍是「暫時無法取得賽事資料」。
5. 對該場有正整數馬號的出賽馬計指數。同一馬號只保留先出現的一匹。沒有馬號的不出列。

回應裏 `model` 是 `Unmeasured feature conditions (no odds baseline)`，`coefficientBasis` 是 `unmeasured-defaults`。每一列有 `horse`、`winProb`、`confidence`、`adjustment` 與 `features`。`horse` 是 `runner.no` 的十進字串。`confidence` 固定是「未量度」。沒有 `odds` 欄。按 `winProb` 由高至低排序，同分再按馬號由小至大，只留前 5 匹。

指數不是校準過的勝率。起點是未量度中性指數 16。只有檔位與已宣告負磅可以加減。缺了的那一項加零，不當成檔號零或磅數零，也不用另一欄頂替。其他條件的係數是 0：有紀錄就記下來，不改名次。

`api/featureConditions.js` 的 `FEATURE_CONDITION_DEFAULTS` 如下。這些數字不是 Size S 的數字。

| 項目 | 未量度預設 |
| --- | --- |
| 中性指數 | 16 |
| 檔位 | 每檔 0.08，參考檔 9，單項絕對值上限 0.8 |
| 已宣告負磅 | 每磅 0.03，參考 118 磅，單項絕對值上限 0.9 |
| 兩項合計 | 絕對值上限 1.2 |
| 跑道、路程、場地、晨操、試閘、配備、傷患、跑法、配對、體重 | 0 |

檔位分是 `(9 − 檔號) × 0.08`，再截在單項上限內。負磅分是 `(118 − 已宣告負磅) × 0.03`，再截在單項上限內。兩項相加後再截在合計上限內。`winProb` 是中性指數加這個合計，四捨五入到一位小數。檔號較參考檔小、或已宣告負磅較參考磅輕，在這個未量度預設裏為正。這不是已量度的內外檔偏差，也不是把磅數換算成已核准的概率。

## 4. 各條件在程式裏怎樣做

共通缺值：缺了就是不存在。不填 `0`，不用同場中位數，不用歷史平均，不用另一欄頂替，也不用賠率頂替。已結束賽事的欄位不填進當前會議。缺值不剔除馬匹，只是該項不加分。

馬匹身份優先用 `runner.horse.code`，形式是 `HK_`、四位年份、再加烙號。烙號用來對傷患頁時，只接受一個大階英文字母加三位數字。同名不同烙號不併成一匹。姓名不用來配對，也不用來合併傷患。出賽馬已經有馬號代碼時，晨操與排位表傷患不再改用馬號去對另一匹馬。

| 條件 | 旗標開啟時 | 會不會改名次 | 缺值 |
| --- | --- | --- | --- |
| 跑道與路程 | 記錄 `raceTrack` 兩邊描述、`raceCourse` 兩邊描述與 `displayCode`，以及正數 `distance`。係數 0。 | 否 | 五段描述都空：跑道描述缺值。`distance` 缺或不是正數：路程缺值。不用 `venueCode` 冒充跑道，不用官方賽果 `detail`。 |
| 場地狀況 | 記錄當前會議的 `go_ch`、`go_en`。係數 0。不建對照表。 | 否 | 兩個文字都空：上下文缺值。不用官方賽果 `detail` 填這兩欄。 |
| 晨操觀察 | 抓第 5 節的會議頁與單駒明細。會議格的快操、踱步、游泳、跑步機、水中步行機、休歇以原文行記錄。單駒頁只留這些類別的較長歷史，不回填空的會議格。係數 0。 | 否 | 空格或該馬不在會議頁：該項缺值。空白不是時間零。近績字串不存。片段連結不用。 |
| 試閘觀察 | 只抓會議頁「試閘」格所引、而且出現在試閘選單裏的日期，再讀該日詳細結果。係數 0。摘要句本身不存成試閘觀察。 | 否 | 沒有可讀的詳細列：該次試閘缺值。`退出` 若寫在走位格，就留在走位；結果格空白仍是空白。 |
| 配備 | `gearInfo` 的非空字串，只當類別代號。不解釋代號。係數 0。試閘頁的配備不取代這一欄。 | 否 | 不是字串，或去掉空白後是空字串：缺值。 |
| 傷患 | 抓第 5 節三頁。每筆有日期、詳情、通過日期，以及該列是否以粗體標成上仗後紀錄。不把文字收成嚴重程度，也不把通過日期收成體能分。係數 0。 | 否 | 該視圖沒有該馬：沒有已公佈紀錄，不是健康證明。通過日期空白或為「-」：不補日期。 |
| 跑法 | 固定缺值，係數 0。計分函數不讀呼叫端送來的跑法字串。 | 否 | 沒有賽前官方分類就是缺值。不從賽後、試閘後或沿途文字推「前置」「居中」「後上」。 |
| 檔位 | 只用當前會議 `barrierDrawNumber`。這是兩項會改指數的條件之一，用第 3 節的未量度預設。 | 是，僅此未量度預設 | 缺、空白、`0`、前導零或不是正整數：缺值，該項加零。不用出賽數目，不用官方賽果 `runner.barrier`，不用試閘排位。 |
| 騎練配對鍵 | 第 6 節的有序代碼對。係數 0。不是勝率，也不是合拍度分數。 | 否 | 任一代碼不可用：沒有配對鍵。不用姓名，不用賠率。 |
| 負磅 | 只用當前會議 `handicapWeight` 的正數。這是另一項會改指數的條件，用第 3 節的未量度預設。 | 是，僅此未量度預設 | 缺、空白、零或不是正數：缺值。不抄 `currentWeight`，不抄 `actualWeight`。 |

`currentWeight` 有正數時記在 `features.weight`，係數 0。它不是負磅。

查詢已經回傳、但這條路徑不讀的鄰近欄位，包括 `penetrometerReadings`、`hammerReadings`、`currentRating`、`internationalRating`、`last6run`、`allowance`、`trainerPreference`、`runner.winOdds`、`finalPosition`，以及獨贏節點的 `hotFavourite`、`oddsDropValue`、`bankerOdds`。

## 5. 公開頁：只在旗標開啟時以 GET 讀取

以下網址都在 `https://racing.hkjc.com`。旗標開啟時以 GET 讀取，不帶憑證、不帶登入、不送 `Authorization`。它們不在 GraphQL allowlist 裏，也沒有被寫進 `api/officialQueries.js`。頁面是 HTML，版面日後可以改；認不出或身份不符就失敗關閉。

現行網域維持不變：當前會議仍是 `https://info.cld.hkjc.com/graphql/base/`。已結束賽事的現有讀取仍只是官方賽果頁，而且只在 `type=official-results`。`api/officialResults.js` 沒有被擴充去取代當前會議。特徵路徑只從該檔借用日期與馬場的日曆解析。

不抓的頁：患喘鳴症資料庫 `overoar`、沿途走勢 `corunning`、馬匹頁 `horse`、速勢能量 `speedpro`、晨操搜尋 `trackworksearch`、官方賽果 `resultsall`。

### 晨操

會議頁：`https://racing.hkjc.com/zh-hk/local/information/localtrackwork?racedate=YYYY/MM/DD&Racecourse=ST` 或 `HV`，再加 `RaceNo=` 場次。

頁首日期、馬場與「第 N 場」必須同時對上所請求的會議與場次。標題列的馬場若與內文不一致，也算不符。

讀取快操、踱步、游泳、跑步機、水中步行機、休歇的格子。試閘格只用來抽出行首日期，不代替詳細試閘。近績不存。晨操片段連結不用。

單駒明細：`https://racing.hkjc.com/zh-hk/local/information/trackworkresult?horseid=HK_年份_烙號`。只抓會議頁上已經出現、而且形式符合的馬匹代碼，不另造代碼。頁內必須含該代碼，否則失敗關閉。只保留晨操類別為快操、踱步、游水、游泳、跑步機、馬匹跑步機、水中步行機、馬匹水中步行機、休歇的列。「出賽」與「試閘」列丟掉。影片連結的文字不當成操練詳情。這頁是較長歷史，不回填會議頁的空格。搜尋頁的參數仍不使用。

### 試閘

選單頁：`https://racing.hkjc.com/zh-hk/local/information/btresult`。只讀 `<option value="DD/MM/YYYY">`。不把這個沒有 `Date` 的頁面上的試閘表當成任何一天的結果。

詳細結果：`?Date=YYYY/MM/DD`。頁上「試閘日期」必須等於所請求的日期，否則失敗關閉。

會抓的日期，只限會議頁試閘格行首引到、而且選單裏也有的日期。行首是 `DD/MM` 或 `DD/MM/YYYY`。沒有年份時，用會議日期的年份；月日晚於會議月日則用上一年。選單以外的日期不假設有資料，也不抓。格內其他分數，例如 `2/8`，不是日期。

詳細列記錄組別、跑道與途程、場地、全組時間、分段時間、馬匹代碼、烙號、騎師姓名、練馬師姓名、排位、配備、頭馬距離、沿途走位、完成時間、結果。時間以頁上文字保存，不換成秒數，也不把空白變成零。「沿途走勢評述」整欄不存。這些姓名與排位不進入騎練鍵，也不進入該場檔位。

### 傷患

1. 排位表：`https://racing.hkjc.com/zh-hk/local/information/veterinaryrecord`，查詢形式與晨操會議頁相同。日期、馬場與場次都要對上。以馬匹代碼對出賽馬；出賽馬沒有代碼時，才用非後備表上的馬號。
2. 宣佈出賽馬匹：`https://racing.hkjc.com/zh-hk/local/information/overecord`。不另造日期參數。頁上印出的日期與馬場必須對上當前會議，否則失敗關閉。只取該場次、而且烙號對得上 `runner.horse.code` 的列。
3. 資料庫：`https://racing.hkjc.com/zh-hk/local/information/ovedatabase`。必須印有「截至」日期，否則失敗關閉。該日期照頁面記錄為 `databaseAsOf`，不要求等於賽事日期，因為這頁不是某一場的會議頁。以烙號對馬，不用馬名。此頁沒有馬場。

同名不同烙號不合併。通過日期為空白或「-」時保持空值。

### 跑法，以及它不是沿途走勢

2026-11-25 的重讀沒有找到賽前官方跑法分類。程式因此把跑法固定留空，不設立「前置」「居中」「後上」。

沿途走勢不是這項標籤。`corunning`、賽果頁評述、試閘頁「沿途走勢評述」、馬匹頁「沿途走位」、`last6run` 與速勢能量頁都不是來源。試閘的沿途走位可以留在該次試閘的欄位，但不會寫進跑法。

## 6. 騎練配對：只有配對鍵

配對的雙方是該匹出賽馬在當前會議已經回傳的騎師與練馬師。用官方代碼，不用姓名。

- 騎師代碼是 `runner.jockey.code`。
- 練馬師代碼是 `runner.trainer.code`。
- 邏輯鍵是有序對：騎師代碼在前，練馬師代碼在後。
- 代碼先只去掉兩端空白。不去大小寫，不全形半形轉換，不以姓名反查代碼，也不讀 `trainerPreference`。
- 去掉兩端空白後，兩邊都必須是非空字串。否則該馬沒有配對鍵。
- 兩個代碼都不含半形豎線 `|` 時，字串為 `騎師代碼|練馬師代碼`。任一代碼含 `|` 時，字串留空，邏輯鍵仍是有序對。
- `name_ch`、`name_en`、官方賽果的 `jockey_ch` 與 `trainer_ch`，以及試閘頁上的姓名，只可顯示。
- `runner.horse.code` 不是這條鍵的一部分。

配對鍵的係數是 0。出賽次數、勝出次數、勝率、入位率與任何強弱分數都還沒有計算。獨贏或位置賠率不是這項統計的替身。

## 7. 位置只可做結算標籤或入位目標

位置（PLA 彩池，或官方賽果的「位置」派彩／名次）不是賽前分析條件。特徵路徑不讀位置賠率，也不讀獨贏賠率。

現有官方賽果解析仍只服務 `type=official-results`。它可以讀到已結束賽事的兩樣資料：

- 名次：`runner.position`。
- 「位置」彩池的派彩列：`dividends` 裏彩池名為「位置」的勝出組合與派彩。

特徵路徑不呼叫這段解析，不把派彩倒數成概率，也不另定入位人數公式。名次與「位置」派彩若日後用作結算標籤或入位目標，只可來自已刊出的官方賽果，而且不得倒灌進賽前條件。

`RACE_MEETINGS_QUERY` 的彩池清單裏出現 PLA，範圍仍是彩池投資、合併彩池或估紅利一類欄位。那些欄位不是本框架的分析條件。當前會議的 `finalPosition` 與 `winOdds` 也不是。

## 8. 資料來源、查詢與介面

當前會議的 GraphQL 文件仍在 `api/officialQueries.js`。兩段匯出字串被測試以 SHA-256 整段鎖定，空白也算在內：

| 常數 | operationName | 長度 | SHA-256 |
| --- | --- | --- | --- |
| `RACE_MEETINGS_QUERY` | `raceMeetings` | 4497 | `bbef8d3eb03bf9c59581e76140e8d3a7fed873b7e84a1a323b02b72f5ba736cb` |
| `WIN_POOL_QUERY` | `sp4e_racing_pmPool` | 1005 | `c08a99ca7cb4f6115db4f23028c1e0fa9e19b2fed9afdf4c404e9c0fd40b2190` |

這兩段字串沒有為本框架改寫。第 4 節已有的當前會議欄位都在鎖定的 `RACE_MEETINGS_QUERY` 內。第 5 節的新頁是另外的 GET，不是這兩段查詢的新欄。

倉庫沒有憑證檔、沒有環境檔，也沒有 SSO 程式。本文不新增這些東西，也不打開任一旗標。

`index.html` 的預測頁按回傳的 `model` 與 `coefficientBasis` 切換文案。只有預測結果已經回來、場次選項存在，而且 `model` 精確等於 `Unmeasured feature conditions (no odds baseline)`、`coefficientBasis` 精確等於 `unmeasured-defaults`，才用旗標開啟的文案。預測清單是空的，只要這幾項同時成立，仍用旗標開啟的文案。尚未執行預測、`model` 是 `Odds-based probability model`、只開啟 Size S（`model` 是 `Odds baseline plus unmeasured Size S adjustments`）、任一欄缺值、兩個欄位只有一個對上，或沒有場次選項時，都用旗標關閉的文案。

旗標關閉時，`.note` 是：「預測只根據當前會議的獨贏賠率，不能按日期或馬場查詢其他賽事。沒有使用晨操、試閘、傷患或其他特徵條件。」`.meta` 留空，而且該段隱藏。頁面最初的 `.note` 也是這句。結果標題是「獨贏」，欄名是「賠率」、「勝出概率」與「信心」。
